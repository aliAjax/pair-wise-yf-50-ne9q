# pair-wise-yf-50 灾后需求评估与任务分派离线前端

源提示词摘要：评估员在弱网环境离线记录家庭需求、特殊照护和现场说明，团队负责人合并重复记录、分派复核任务并追踪进展；多人修改同一记录时提供字段级冲突展示，不静默覆盖。

## 河湾片区恢复分组派工（`utils/dispatch.ts`）

把需求记录、任务分派、冲突处理和待同步队列接成一条**可恢复流水线**，四步检查点：
接收补传 → 冲突冻结 → 派工 → 同步送达（`runDispatch`）。任一步中断后重试只补做未完成步骤，全程持久化到 localStorage。

- **重复家庭只保留一条**：补传按「户主+社区」归一，需求取并集，差异字段生成字段冲突；手动合并时已派/在队任务与未决冲突全部迁到保留记录。
- **冲突未定稿不占名额**：有「待处理」冲突的家庭冻结，派工排空时跳过，排队任务留在队列；冲突定稿后自动解冻。
- **紧急度变化重排**：只重排「排队」任务（紧急优先、同级先到先得），已派出/进行中任务继续跑、顺序不动。
- **并发抢占**：`contendSlot` 严格按到达时间串行决出唯一成功者；名额满后到者任务留在队列。
- **断点续跑与幂等**：批次 `batchId` 去重、派工状态转移幂等（已派出不能重派）、发件箱 `requestId` + `sent` 标志保证送达不重发；完工释放小组名额。
- 小组容量=同时可进行的现场复核数，「已派出」与「进行中」均占用名额，「已完成」释放。
